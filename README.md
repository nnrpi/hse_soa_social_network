# Социальная сеть

## Сервисы

### Основные сервисы
- **UserService** - Сервис пользователей, аутентификация, профили
- **PostsService** - Сервис постов, комментарии, хэштеги
- **Posts API Service** - REST API для взаимодействия с постами (просмотр, лайк, комментарий)
- **Posts gRPC Service** - gRPC сервис с основной функциональностью для постов
- **Kafka** - Система обмена сообщениями для событий

## События Kafka
- Регистрация пользователей (топик: user_registrations)
- Просмотры постов (топик: post_views)
- Лайки постов (топик: post_interactions)
- Комментарии к постам (топик: post_comments)

## Запуск

```
cd src
make setup
make build-posts
make run
```

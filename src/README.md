# Социальная сеть - Исходный код

## Структура проекта

- `proxy-service/` - Прокси-сервис, единая точка входа в API
- `user-service/` - Сервис пользователей
- `post-service/` - Сервис постов
- `posts-api-service/` - REST API сервис для постов
- `posts-grpc-service/` - gRPC сервис для постов
- `statistics-service/` - Сервис статистики (Kafka → ClickHouse)
- `bin/` - Скомпилированные бинарные файлы
- `tests/` - Тесты

## Новые возможности

В рамках последнего обновления были добавлены:

1. REST API для работы с постами (posts-api-service)
2. gRPC сервис с основной функциональностью для постов (posts-grpc-service)
3. Интеграция с Kafka для обработки событий
4. Методы API:
   - Просмотр поста
   - Лайк поста
   - Комментарий к посту
   - Получение всех комментариев поста

## Работа с Kafka

События отправляются в следующие топики Kafka:
- `user_registrations` - События регистрации пользователей
- `post_views` - События просмотра постов
- `post_interactions` - События лайков постов
- `post_comments` - События комментирования постов

## Запуск

```bash
make setup
make build-posts
make run
make clean
```
